# Bancos de som embarcados

Qualquer `.sf2` ou `.dls` colocado aqui é copiado para dentro do app e
carregado automaticamente — no Mac e no iPad, sem o usuário fazer nada.

Os arquivos em si **não vão para o repositório** (ver `.gitignore`): são
grandes, e cada um tem a sua licença. Esta pasta existe mesmo vazia para que
um clone limpo continue compilando; sem banco, o app cai no sintetizador.

Instalado hoje: **Upright Piano KW** — piano vertical Kawai gravado pelo
projeto FreePats, sob **CC0** (domínio público). Sem atribuição obrigatória.
